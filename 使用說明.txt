小黑桌寵　V1.0.1 —— 小黑（害羞、愛睡、會撒嬌的黑色台灣米克斯）

【V1.0.1 修正（2026-10-31）】
- 走路重做：8 張圖，四條腿輪流往前跨、步伐大一點，往前擺的腳會抬起來；身體移動的速度跟腳步對齊，腳不會在地上滑。
- 撒嬌改成開心的樣子：歪頭、耳朵豎著、瞇眼笑（原本耳朵往後貼，看起來像被打）。
- 側躺睡照小黑的照片重畫：真的倒向一邊、四隻腳伸直。
- 趴下照小黑的照片重畫：一隻前腳往前伸、另一隻收在胸前。

【V1.0.0 第一版（2026-10-31）】
- 小黑會在桌面上走來走去：站著會呼吸、眨眼、搖尾巴，也會坐下、趴下、打哈欠、歪頭、聞聞地上，偶爾跑一跑。
- 點他一下會開心；滑鼠停在他身上會撒嬌，一直摸會翻肚子給你摸。
- 可以抓起來拖著走（腳在空中划），用力甩出去會飛出去再滑一段停下。
- 沒人理他會自己睡覺，晚上會自動睡；有四種睡姿。
- 右鍵選單、右下角小黑頭像（點一下叫他過來）、五種尺寸、永遠在最上層、檢查更新。

【怎麼開】
- 按兩下 START_Black.cmd。不用安裝、不需要系統管理員權限。
- 一次只會有一隻小黑；再按兩下 START_Black.cmd，小黑會跑到滑鼠旁邊。
- 打不開時，黑色視窗會說明原因，並用記事本打開 docs\start_help.txt。
- 從 GitHub 下載 ZIP 的話：解壓縮前先對 ZIP 按右鍵 →「內容」→ 勾選「解除封鎖」。

【怎麼跟小黑玩】
- 點小黑一下：開心吐舌頭、搖尾巴、跳一下。睡著時點一下會叫醒他。
- 滑鼠停在小黑身上：小黑撒嬌（耳朵往後、瞇眼）；一直摸，他會翻肚子給你摸；手拿開他就起來。
- 按住小黑拖著走：小黑的腳在空中划；用力甩出去，小黑會飛出去、碰到螢幕邊緣會彈回來，滑一段才停下（膽小的小黑會被嚇到）。
- 小黑自己會走動、坐下、趴下、打哈欠、歪頭、聞聞地上，偶爾跑一跑。
- 大約 10 分鐘沒人理小黑：打哈欠、趴下來睡覺（趴著睡、捲成一團、側躺、翻肚睡）。晚上 11 點到早上 6 點會自己去睡。
- 右下角（時鐘旁）的小黑頭像：左鍵點一下，小黑跑到滑鼠旁邊；右鍵有「叫小黑過來」和「結束」。

【右鍵選單】（滑鼠停在每一項上面會出現說明）
- 心情 ♥♥♥♡♡：聽小黑說他現在的心情。常摸摸他、陪他玩，心情會變好；太久沒理他，心情會慢慢變差。
- 睡覺／叫醒：醒著時顯示「睡覺」，睡著時顯示「叫醒」。
- 動作：坐下、趴下、打哈欠、歪頭、聞聞、跑一跑、撒嬌。
- 走動：自由走動（關掉就待在原地）、追滑鼠、叫小黑過來。
- 設定：尺寸（迷你／小／一般／大／巨大）、永遠在最上層、晚上自動睡、沒人理會自己睡。
- 關於：小黑介紹（版本）、檢查更新、自動檢查更新（每天看一次）。
- 結束：讓小黑休息（關閉程式）。
- 之後的版本會一版一版加上：餵點心、喝水、玩具、換衣服、鬧鐘、番茄鐘、健康提醒等。

【安全性】
1. 平常不連網路。只有「檢查更新」（手動，或每天自動一次）會連到 GitHub 的 chienan822454/Black_Desktop_pet，
   只看、只下載小黑自己新的或改過的檔案，下載和更新前都會先問你，不會刪除任何檔案。
2. 不改 Windows 設定、不安裝東西、不需要系統管理員權限，也不會繞過 PowerShell 的安全設定。
3. 只寫小黑自己的檔案：設定和心情在 %APPDATA%\BlackPet；出問題時在這個資料夾寫 BlackPet_Error_*.txt（每次最多 5 個）。
4. 放在 OneDrive 資料夾時，會把「小黑這個資料夾」設成「一律保留在此裝置上」，避免圖片只在雲端讀不到。

【出問題時】
- 按兩下 DIAG_Black.cmd（診斷模式）：黑色視窗會一直開著，顯示錯誤訊息。
- 把資料夾裡最新的 BlackPet_Error_*.txt 給維護的人看。

【檔案】
- 沒有改到的檔案（日期比較舊）仍是目前版本的一部分，請不要刪除。
